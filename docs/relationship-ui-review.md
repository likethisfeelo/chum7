# 이번 세션 범위 UI 검토 및 개선 계획

> 작성: 2026-07-23 · 범위: 이번 세션에서 만들거나 건드린 UI (익명·마당 댓글·리더 모드·친구·아카이브)

## 검토 대상 UI
| 화면 | 세션 변경 |
|---|---|
| 마당 FeedPage / CommentSection | 익명 토글 제거(P1-1), 아무개N 표시(P1-3), 댓글 삭제(P1-5) |
| 챌린지 ChallengeFeedPage | 인증카드 displayName(P1-2), 리더/참여자 모드 토글·👑(P1-6) |
| FriendsPage (신규) | 추천·받은요청·내친구 (P2 B) |
| FriendArchivePage (신규) | 요약·동의·타임라인 (P3) |
| admin (로그인/퀘스트/보드) | 비번찾기, 퀘스트 생성/수정, 보드 경로 |

---

## 🔴 크리티컬 — 이번에 수정 완료
1. **친구 기능 진입점 없음** → 마이(/my) 헤더에 "친구" 버튼 추가. (라우트만 있고 네비에 없어 도달 불가였음)
2. **아카이브 동의 체크박스가 저장 상태 미반영** → relationship-summary가 내/상대 동의 반환, 체크박스 초기화 + 상호 동의 상태 표시.

## 🟡 개선 권장 (다음 단계)
3. **친구 요청 알림 딥링크** — friend.requested 알림 탭 시 /friends로 이동 연결 확인·보강. (알림 클릭 네비 매핑 점검)
4. **아카이브 타임라인 페이지네이션** — API는 nextCursor 있음, 프론트는 첫 페이지만. "더 보기" 추가.
5. **마당 CommentSection 레이아웃** — 아무개N·"나"·삭제가 한 줄에 몰려 좁을 수 있음. 삭제를 아이콘/더보기로.
6. **추천 사유 문구 다듬기** — "자주/종종/가끔 마주쳤어요" + 함께한 챌린지 수. 카피 검토.
7. **리더 모드 토글 발견성** — 리더에게만 노출되나 안내 문구 약함. "리더로 작성 중" 같은 상태 강조.

## 🟢 폴리시(낮음)
8. FriendsPage/ArchivePage 로딩·빈 상태·에러 스켈레톤 통일.
9. 인증 피드 카드 아바타가 displayName 첫 글자 — 동물 이모지 매핑 등 시각 개선 여지.
10. 아카이브 실콘텐츠(단계 E) 프론트 — 현재 참조만 반환, 딥링크 버튼(원본 보기)은 글로벌 플래그 켤 때 구현.

## 실행 계획 (권장 순서)
1. **(완료)** 진입점 + 동의 상태 — 기능 도달성·정합성.
2. **배포 후 실검증** — 친구 추천/아카이브가 실제 데이터로 도는지 확인하며 3·4·5 우선순위 재조정.
3. **알림 딥링크(3) + 타임라인 더보기(4)** — 사용 흐름 완성.
4. **레이아웃·카피 폴리시(5~7)** — 실사용 피드백 반영.
5. **단계 E 프론트(10)** — 글로벌 플래그 오픈 시.

> 원칙: 3~10은 실배포·실사용 없이 미리 다듬기보다, **배포 후 실제 화면 보고** 우선순위를 정하는 게 효율적. 크리티컬 2건만 먼저 처리(완료)했다.
