# 앱 아이콘 (PWA / 홈 화면에 추가)

이 폴더에 **`icon-512.png`** 파일 하나만 넣으면 됩니다.

- 파일명: `icon-512.png`
- 권장 규격: **512 × 512 정사각형 PNG** (제공된 CHUM 7 손 모양 이미지)
- 이 한 파일이 다음 모두에 사용됩니다:
  - PWA 매니페스트 아이콘 (Android/데스크톱 설치)
  - iOS `apple-touch-icon` (홈 화면에 추가)
  - 앱 설치 안내 시트의 미리보기

리사이즈 도구가 없어 별도 192px 파일은 만들지 않고, 브라우저가 512px 파일을
축소해서 사용하도록 매니페스트에 설정해 두었습니다. (필요하면 나중에
`icon-192.png`를 추가하고 `vite.config.ts`의 `icons` 배열에 항목을 넣으면 됩니다.)

> 이 파일을 넣은 뒤 프론트엔드를 다시 빌드/배포해야 반영됩니다.
